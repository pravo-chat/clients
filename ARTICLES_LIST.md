# Список юридических статей / вопросов

**Структура:** Все Q&A объединены в одну страницу по каждой тематике. Каждый вопрос имеет якорь `#slug` на странице категории.

**Правило при добавлении новой статьи:**
1. Добавить Q&A блок в соответствующий `category/index.html` (через скрипт `merge_articles_to_category.py` или вручную)
2. Добавить запись в этот список
3. Обновить ссылки в `legal-questions-answers.html`
